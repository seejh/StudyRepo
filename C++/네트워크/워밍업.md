# 네트워크 분류
메시지 교환 방식에 따른 네트워크 분류 (패킷 교환, 회선 교환)

## 회선 교환 방식
메시지를 주고 받기 전 회선을 설정한 뒤(전송로 예약, 확보) 해당 회선을 통해 메시지를 주고 받는 형식<br/>

전송로를 확보하고 난 후에 메시지를 주고 받기 때문에 통신하는 동안 정보의 양이 비교적으로 일정하다는 장점이 있으나
회선의 이용 효율이 낮아질 수 있다. (전송로 공유가 아니라 점유이며 연결만 해놓고 그 통로를 사용 안하거나 적게 쓰면
이용 효율이 낮아질 수 있다는 것)<br/>

패킷 스위치를 사용한다.<br/>

## 패킷 교환 방식
메시지를 패킷이라는 단위로 쪼개어 전송, 쪼개어 전송된 패킷들은 수신지에서 재조립.
전송로의 이용 효율이 높으며(공유하여 사용하기에) 현대 인터넷은 대부분 패킷 교환 방식.
패킷 스위치, 라우터를 사용한다.<br/>

패킷이 패킷의 송수신지를 가지고 있고 스위치와 라우터가 패킷이 이동할 최적의 경로를 결정한다.<br/>
<img width="754" height="366" alt="image" src="https://github.com/user-attachments/assets/9f6baa9e-75d6-43e2-a037-d486ca1e2f27" />

### 패킷
패킷은 해당 패킷에 대한 제어 정보와 보내려는 데이터로 구성되어 있다.<br/>
header(헤더, 제어 정보) + payload(페이로드, 전송하려는 데이터)<br/>

### 송수신지 유형별 전송 방식
* 유니캐스트<br/>
하나의 수신지에 메시지 전송
송신지와 수신지가 일대일로 메시지를 주고 받는다

* 브로드캐스트<br/>
네트워크상의 모든 호스트에게 전송

* 멀티캐스트<br/>
네트워크 내에서 동일 그룹에 속한 호스트에게만 전송

* 애니캐스트<br/>
네트워크 내의 동일 그룹에 속한 호스트 중 가장 가까운 호스트에게 전송

# 네트워크 참조 모델 (OSI 7 계층)
OSI 모델(OSI 7계층)과 TCP/IP 모델(TCP/IP 4계층, OSI 모델의 간략화)이 있다.<br/>
<img width="549" height="356" alt="image" src="https://github.com/user-attachments/assets/8d74115a-17a1-49d0-b901-7d1241cb9d60" /><br/>

## OSI 7 계층
* 물리 계층 (physical layer)<br/>
OSI 모델 최하단, 1과 0으로 표현된느 비트 신호를 주고 받는 계층<br/>
장치 간의 물리적 연결(유선, 무선)을 하고 전기, 빛, 전파 등의 아날로그 신호와 디지털 신호(0, 1)간의 변환<br/>

* 데이터 링크 계층 (data link)<br/>
네트워크 내(LAN) 주변 장치 간의 정보를 올바르게 주고 받기 위한 계층<br/>
물리 계층이랑 묶어서 하나로 보기도 한다.<br/>

* 네트워크 계층 (network)<br/>
데이터 링크가 같은 네트워크(LAN) 내에서 올바른 전송지를 찾기 위한 영역이라면 네트워크 계층은 다른 네트워크(WAN)와의 통신에서
올바른 전송지를 찾기 위한 내용이다.<br/>

* 전송 계층 (transport)<br/>
통신의 신뢰성과 안정성을 위한 기술들이 있는 곳 (tcp, udp)<br/>
또한 사용자의 프로세스를 식별하기 위한 포트를 사용하는 계층<br/>

* 세션 계층 (session)<br/>
세션이라는 것은 it에서 다채롭게 사용된다.<br/>
여기서의 세션은 통신을 주고 받는 각 호스트들의 프로그램 간의 연결 상태를 말한다.<br/>
세션을 관리하는 계층<br/>

* 표현 계층 (presentation)<br/>
문자를 컴퓨터가 이해할 수 있는 코드로 변환하거나, 압축, 암호화

* 응용 계층 (application)<br/>
사용자 및 사용자가 이용하는 프로그램에 다양한 네트워크 서비스

## TCP/IP 4 계층
* 네트워크 액세스 계층 (network access)<br/>
OSI 모델의 "데이터 링크"와 유사<br/>
물리 꼐층은 취급하지 않는다.<br/>

* 인터넷 계층 (internet)<br/>
OSI 모델의 "네트워크"와 유사<br/>

* 전송 계층 (transport)<br/>
OSI 모델의 "전송"과 유사<br/>

* 응용 계층 (application)<br/>
OSI 모델의 "세션+표현+응용"과 유사<br/>

# 트래픽 (traffic)
네트워크 내의 정보량.
주로 노드에서 측정 (특정 시점에 노드를 경유하는 정보량)
왜 알아야 하는가? -> 과도한 트래픽은 과부하(성능 저하) 발생

성능 파악

## 네트워크 성능 지표
* 처리량 (throughput)<br/>
단위 시간당 네트워크를 통해 실제로 전송되는 정보량<br/>
보통 실시간성이 강조된 지표로 많이 사용<br/>
표현 단위: bps(bit/s), Mbps(Mbit/s), pps(p/s, packets per seconds)<br/>

* 대역폭 (bandwidth)<br/>
아래의 2가지 뜻이 있으면 많이 오용되어 사용된다.<br/>
신호 처리 영역: 주파수의 범위<br/>
컴퓨팅 영역: 최대 처리량<br/>

* 패킷 손실 (packet loss)
송신, 수신되는 패킷이 손실<br/>
손실률(백분위) 또는 손실된 패킷 수 등의 단위 사용<br/>
