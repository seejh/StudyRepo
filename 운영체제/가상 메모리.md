# 가상 메모리 (Virtual Memroy)
앞에서 배운 메모리 관리 방법 중에서 페이징 기법(비연속 할당 방식)을 사용하는 것을 전제로 한다.(대체로 페이징 기법을 사용한다고 한다)


Demand Paging
실제로 필요할 때 page를 메모리에 올리겠다.

얻을 수 있는 효과
I/O 감소
메모리 사용량 감소
빠른 응답 (한정된 메모리 공간일 때 유효한 데이터만 올라가므로 이에 대한 빠른 응답이라는 소리)
