## 메모리 관리 기본

### 주소 바인딩
프로그램의 논리적 주소를 실제 물리적 메모리 주소로 매핑하는 과정.

<table>
  <th>바인딩 방식</th><th>주소 결정 시점</th><th>설명</th>
  <tr>
    <td>컴파일 타임 바인딩(Compile)</td>
    <td>컴파일 시점</td>
    <td>컴파일할 때 특정 물리적 메모리 위치로 고정된다(절대 주소). 주소 변환이 없어서 실행 속도가 빠르지만
    주소를 바꾸려면 재컴파일해야 하며 요새는 사용하지 않는 방식이다.</td>
  </tr>
  <tr>
    <td>로드 타임 바인딩(Load)</td>
    <td>프로그램 실행 시점(메모리 로드 시점)</td>
    <td>컴파일하면 재배치 가능 코드(Reallocation Code)라는 걸로 </td>
  </tr>
  <tr>
    <td>런 타임 바인딩(Run)</td>
    <td>프로그램 실행 중에</td>
    <td></td>
  </tr>
</table>
