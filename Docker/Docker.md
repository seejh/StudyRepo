### 도커 핵심 개념
Dockerfile:
프로그램을 실행하기 위해 필요한 패키지, 소스코드, 환경 변수 등을 기록한 텍스트 레시피

Image:
도커파일을 빌드하여 만든 실행 가능한 패키지
Container:
이미지를 실행한 실제 상태

### 윈도우에서 도커 사용
도커는 기본적으로 리눅스 기술을 기반으로 한다. 윈도우에서 도커를 실행하려면 윈도우에 리눅스를 설치하여 그 위에서 사용해야 한다.

WSL
윈도우에 리눅스를 설치하는 기술.
관리자모드로 cmd를 열고 wsl --install 명령 입력 후 재부팅



도커는 기본적으로 리눅스의 기술을 기반으로 한다. 윈도우에서 도커를 실행하려면 WSL2이 필요.
도커 데스크톱을 설치하면 이 과정을 자동으로 함께 세팅해준다.

윈도우 10 이상(home, pro 모두 가능)
가상화(Virtualization) 활성화 필요, "작업 관리자 -> 성능 탭 -> cpu -> 가상화: 사용함"으로 확인 가능.

wsl2 설치
cmd 관리자 권한 실행
"wsl --install" 이후 재부팅

도커 공식 홈페이지 접속 후 도커 데스크톱 다운로드
설치할 때 옵션 "Use WSL 2 instead of Hyper-V" 항목이 체크되어 있는지 확인
